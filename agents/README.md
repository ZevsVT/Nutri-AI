# Nutri-AI AI Coding Guardrails

Skill pack for AI coding agents working on Nutri-AI.

Core principle:

> Understand the system first. Trace the data flow. Make the smallest safe change. Verify the result. Report exactly what changed.

Recommended location:

```text
.agents/
└── skills/
    ├── SKILL.md
    ├── workflow-tracing.md
    ├── change-control.md
    ├── data-integrity.md
    ├── architecture-safety.md
    ├── verification.md
    └── change-log.md
```

Works as a project-level guardrail for Cursor, Claude Code, Codex, GitHub Copilot Agent, and similar coding agents.
